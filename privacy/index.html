Autom8 Integrations: Privacy Policy

Effective date: 26 October 2026

Who runs this app

Autom8 Integrations (Meta App ID 3688512777983352) is a private advertising tool built and run by Faisal Ahmed to manage ads through the AI assistant Claude.

Contact: faisalahmed7170@gmail.com

Who uses the app

The app is not offered to the public. Only people who hold a role on the app use it, to report on and manage ads for the brands they run. It does not offer Facebook Login to the public and does not collect data from people who view ads.

What data the app accesses

When a person with a role on the app connects their own Meta account, the app uses that person's access token to read and, when they instruct it, change:

  • their Meta user ID and name;
  • ad accounts, campaigns, ad sets, ads, ad creatives, ad images and videos, and their settings;
  • aggregated advertising performance data, such as spend, impressions, clicks and purchases. Meta provides this data aggregated, not about identifiable individuals;
  • identifiers of the Facebook Pages and Instagram accounts used as ad identities, and catalog information used in ads;
  • ad account activity history, which can include the names of people and apps that made changes.

Permissions requested: ads_management, ads_read, business_management, catalog_management, pages_show_list, pages_read_engagement, pages_manage_metadata, pages_manage_ads, public_profile.

How the data is used

Only to:

  • produce advertising reports for the brands the app's users run;
  • create and edit ads when the user asks for a specific change. New campaigns, ad sets and ads are created paused, and launches, budget changes and deletions need separate confirmation.

Meta Platform data is not sold, used to build profiles of individuals, used for eligibility decisions, or shared with data brokers.

Where data goes and how long it is kept

  • Requests run on the user's own computer. The app has no server or database of its own.
  • Access token: stored only on that computer, in a file readable only by its owner. It is never printed or logged. It expires automatically and is replaced when renewed or deleted when access is revoked.
  • API responses: passed directly to the user's AI assistant, Claude by Anthropic, to answer their request. The app does not save them.
  • Audit log: for each request the app keeps a local record of the time, the API path (which contains account or object IDs), the HTTP status and, for changes, a short description of the approved change. It contains no tokens, parameter values or response content. Entries are deleted automatically after 6 months, and no copy is kept.
  • Service providers: Meta Platforms (the API itself) and Anthropic (the AI assistant).

Your choices and deletion

  • You can disconnect the app at any time in Facebook Settings & privacy → Settings → Business integrations (or Apps and websites) by removing "Autom8 Integrations". This revokes its access.
  • To ask for deletion of data the app holds about you, follow the data deletion instructions or email faisalahmed7170@gmail.com. You'll get a reply within 30 days.

Security

Tokens are stored in owner-only files on the user's computer. Requests go only to Meta's official API over HTTPS. Only people with a role on the app can use it.

Changes

This page and its effective date will be updated if the app's data use changes.
